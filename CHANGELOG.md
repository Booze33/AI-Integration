# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-20

### Added

- Initial release of AI Integration Boilerplate.
- Monorepo structure with backend, frontend, and shared types packages.
- Backend modules for auth, chat, provider config, pipeline, webhooks, dashboard, and diagnostics.
- Frontend pages for authentication, dashboard, chat, uploads, and settings.
- Local Docker infrastructure for PostgreSQL and Redis.
- Project documentation for API, user guide, and Vercel deployment.
